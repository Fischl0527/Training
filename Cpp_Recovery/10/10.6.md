## 1. 核心知识速查

| 知识点 | 常用写法 | 说明 |
|---|---|---|
| 定长 `vector` | `vector<int> a(n);` | 已知有 `n` 个元素 |
| 动态 `vector` | `vector<int> a;` | 初始为空，后续动态添加 |
| 添加元素 | `a.push_back(x);` | 在末尾加入 `x` |
| 元素数量 | `a.size()` | 返回当前元素个数 |
| 判断为空 | `a.empty()` | 空则为 `true` |
| 只读遍历 | `for (auto x : a)` | `x` 是元素副本 |
| 修改遍历 | `for (auto &x : a)` | `x` 引用原元素 |
| 升序排序 | `sort(a.begin(), a.end());` | 需要 `<algorithm>` |
| 降序排序 | `sort(a.begin(), a.end(), greater<int>());` | 通常配合 `<functional>` |
| 类型转换 | `static_cast<double>(sum)` | 避免整数除法 |
| 无限循环 | `while (true)` | 配合 `break` 处理结束标志 |

### `auto` 与引用
```cpp
for (auto x : a)      // 对 int vector 来说≈ int x，读取副本
for (auto &x : a)     // ≈ int &x，直接操作原元素
```

输入 `vector` 时：
```cpp
vector<int> a(n);
for (auto &x : a)
    cin >> x;
```

输出时：
```cpp
for (auto x : a)
    cout << x << " ";
```

关键区别：
```cpp
for (auto x : a) x = 0;      // 原数组不变
for (auto &x : a) x = 0;     // 原数组全部被修改
```

## 2. `vector` 两种使用模式

### 已知数量
```cpp
int n;
cin >> n;

vector<int> a(n);
for (auto &x : a)
    cin >> x;
```

### 不知道数量，以 `-1` 结束
```cpp
vector<int> a;
int x;

while (true) {
    cin >> x;

    if (x == -1)
        break;

    a.push_back(x);
}
```

这正是 `vector` 相比 `int a[100]` 的优势：**不需要提前猜长度。**

因此今天最后一道题中：

```cpp
#define MAXSIZE 100
```

其实没有必要。若确实需要常量限制，现代 C++ 更推荐：

```cpp
constexpr int MAX_SIZE = 100;
```

而不是单纯用 `#define`。

```cpp

```

## 4. 平均值与类型转换

错误：
```cpp
int sum = 26;
int n = 8;
double average = sum / n;    // 实际先得到 3
```

正确：
```cpp
double average = static_cast<double>(sum) / n;   // 3.25
```

因为：
```text
int / int       → 整数除法
double / int    → 浮点除法
```

如果 `sum` 本身已经是：
```cpp
double sum = 0;
```
则直接：
```cpp
double average = sum / a.size();
```
即可，不必再次 `static_cast<double>(sum)`。

## 5. 今天踩过的坑

| 问题 | 原因 | 推荐写法 |
|---|---|---|
| `vector<int> a; cin >> a[0];` | 空 vector 中不存在 `a[0]` | `push_back()` 或先 `vector<int> a(n)` |
| `for (auto x : a) cin >> x;` | 修改的是副本 | `for (auto &x : a)` |
| `sum / n` 得不到小数 | `int / int` 为整数除法 | `static_cast<double>(sum) / n` |
| `n == 0` 后求平均值 | 除零 | 输入后先检查 `n <= 0` |
| 空 vector 直接 `a[0]` | 越界，未定义行为 | 先 `a.empty()` |
| 正/负/零分别遍历三次 | 重复扫描 | 一个循环同时统计 |
| 用 `max`、`min` 作变量名 | 容易与标准库函数混淆 | `maxValue`、`minValue` |
| 为动态 vector 再设 `MAXSIZE` | 又退回固定数组思维 | 无特殊要求就让 vector 自己增长 |

空数组检查模板：
```cpp
if (a.empty()) {
    cout << "No data!" << endl;
    return 0;
}
```

输入数量检查：
```cpp
if (n <= 0) {
    cout << "n must be greater than 0." << endl;
    return 0;
}
```

## 6. 合并遍历思维

原思路可能是：

```text
遍历一次统计正数
再遍历一次统计负数
再遍历一次统计 0
```

更好的写法：

```cpp
int positive = 0;
int negative = 0;
int zero = 0;

for (auto x : a) {
    if (x > 0)
        positive++;
    else if (x < 0)
        negative++;
    else
        zero++;
}
```

核心思维：

> 已经拿到当前元素时，把针对它的相关任务尽量一起完成。

## 7. 最大值、最小值、求和模板

```cpp
if (a.empty())
    return 0;

int maxValue = a[0];
int minValue = a[0];
int sum = 0;

for (auto x : a) {
    if (x > maxValue)
        maxValue = x;

    if (x < minValue)
        minValue = x;

    sum += x;
}

double average =
    static_cast<double>(sum) / a.size();
```

这里两个独立的 `if` 比：

```cpp
if (...)
    ...
else if (...)
    ...
```

更能表达“分别检查最大值与最小值”这两个独立任务。

## 8. 第一课最终综合模板

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main() {
    vector<int> a;
    int num;

    while (true) {
        cin >> num;

        if (num == -1)
            break;

        a.push_back(num);
    }

    if (a.empty()) {
        cout << "No data!" << endl;
        return 0;
    }

    int maxValue = a[0];
    int minValue = a[0];
    int sum = 0;

    for (auto x : a) {
        if (x > maxValue)
            maxValue = x;

        if (x < minValue)
            minValue = x;

        sum += x;
    }

    double average =
        static_cast<double>(sum) / a.size();

    cout << "Size: " << a.size() << endl;
    cout << "Max: " << maxValue << endl;
    cout << "Min: " << minValue << endl;
    cout << "Average: " << average << endl;

    sort(a.begin(), a.end());

    for (auto x : a)
        cout << x << " ";

    return 0;
}
```
